# Hermes robotics skills

Hardware-oriented skills and reference implementations used with Hermes.

## Included skills

- [`rebot-rs-wrist-pick-place`](rebot-rs-wrist-pick-place/) — safe,
  preplanned eye-in-hand pick/place for the reBot RS arm and wrist RealSense.
- [`rebot-rs-wrist-pick`](rebot-rs-wrist-pick/) — pick, verify, lift, and keep
  holding so Hermes can make a separate placement decision.
- [`rebot-rs-wrist-place`](rebot-rs-wrist-place/) — consume the same-session
  pick certificate, plan scene-relative placement, release, and home.

Secrets, machine-specific calibration JSON, generated images, and runtime output
are intentionally excluded.
